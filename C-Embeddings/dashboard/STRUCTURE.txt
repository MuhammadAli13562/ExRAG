FEATURES
========

🎨 UI Components
├── Header (gradient title)
├── Sidebar
│   ├── Collection selector (dropdown)
│   ├── Collection stats (metrics)
│   ├── Query settings (top-k slider)
│   └── Advanced filters (chapter, page, type)
├── Main Area
│   ├── Query interface (text input + buttons)
│   ├── Results summary (3 metrics)
│   └── Result cards (rank, title, similarity, metadata, preview, expandable)
└── Footer (credits)

🎨 Visual Design
├── Gradients
│   ├── Purple (#667eea → #764ba2) - primary
│   └── Pink (#f093fb → #f5576c) - accents
├── Colors
│   ├── Green (#4ade80) - high similarity
│   ├── Yellow (#fbbf24) - medium similarity
│   └── Red (#f87171) - low similarity
├── Typography
│   ├── SF Pro Display - body
│   └── Courier New - code
└── Effects
    ├── Hover animations
    ├── Smooth transitions
    └── Box shadows

🔍 Search Flow
├── 1. Select collection (sidebar dropdown)
├── 2. Set top-k (slider, 1-20)
├── 3. Add filters (optional: chapter, page, type)
├── 4. Enter question (text input)
├── 5. Click Search 🚀
├── 6. View loading spinner
└── 7. Explore results
    ├── Check similarity scores
    ├── Read metadata
    ├── Preview text
    └── Expand for full content

TECHNOLOGY STACK
================

Framework
├── Streamlit 1.28+ (web UI)
├── Python 3.11+ (backend)
└── HTML/CSS (custom styling)

Database
├── ChromaDB (vector storage)
└── HNSW index (similarity search)

AI/ML
├── OpenAI embeddings (text-embedding-3-small)
└── Cosine similarity (distance metric)
